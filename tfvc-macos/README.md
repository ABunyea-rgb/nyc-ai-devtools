# TFVC macOS Starter Pack

## Purpose
This folder contains a TFVC starter kit for macOS.

## Quick start
1. Read `docs/QUICKSTART.md`.
2. Copy this folder to your machine.
3. Fill in your own TFVC values (`TFVC_COLLECTION_URL`, `TFVC_SERVER_PATH`, local paths).
4. Run `scripts/bootstrap-tfvc-workspace.sh`.
